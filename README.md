# Backend Foundations

A practical backend engineering project built as part of a 3-day foundation track.

The project starts with JavaScript fundamentals, moves to TypeScript, and then turns the task management logic into a REST API using Node.js and Express.

## Tech Stack

* JavaScript
* TypeScript
* Node.js
* Express
* Git & GitHub

## Project

A simple **Task Management REST API** built progressively throughout the training.

The project covers:

* JavaScript backend fundamentals
* TypeScript and type safety
* Node.js and HTTP
* Express REST APIs
* Routing, controllers, services and middleware
* Git branching, commits and pull requests

## Getting Started

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Start

```bash
npm start
```
